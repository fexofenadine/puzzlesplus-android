The canvas is the screen's size; below 100% the shader draws a smaller picture into a framebuffer and a second pass stretches it with a Catmull-Rom filter (nine bilinear reads), so thin neon lines stay crisp where plain stretching made blocks (2026-11-21, the user found Synthwave pixelated at 1080p).
